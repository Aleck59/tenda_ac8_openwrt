# Tenda AC8 v1: железо, флеш, калибровка

Всё ниже получено разбором дампа программатора (`ac8_good_dump`) и стоковой
прошивки `V02.03.01.78` (eCos, загрузчик Realtek v3.4.13): дизассемблированием
загрузчика и функций eCos, которые читают заводские параметры.

## Аппаратная часть

| Узел | Чип | Подключение |
|---|---|---|
| SoC | Realtek RTL8197FH, MIPS 24Kc 1 ГГц, little-endian | — |
| ОЗУ | 64 МиБ DDR2 | — |
| Флеш | SPI NOR, штатно 2 МиБ, **в этом проекте 8 МиБ** | контроллер SPI (DW SSI) SoC |
| 2.4 ГГц | встроенный в SoC WMAC RTL8197F, 2T2R 802.11n | 0x18640000, IRQ CPU IP6 |
| 5 ГГц | RTL8812FR, 2T2R 802.11ac (PCI ID `10ec:f812`) | PCIe SoC |
| Коммутатор | RTL8367RB-VB (chip id 0x6367) | RGMII на порт 6 (EXT1), управление по SMI |

### GPIO (линейная нумерация: банк ABCD = 0..31, EFGH = 32..63)

| GPIO | Пин | Назначение |
|---|---|---|
| 35 | E3 | единственный светодиод на корпусе, активный 0 |
| 36 | E4 | кнопка WPS/RST, активный 0 (удержание при включении — аварийный режим загрузчика) |
| 55 | G7 | SMI SDA (MDIO) RTL8367 |
| 56 | H0 | SMI SCK (MDC) RTL8367 |

Регистры банка EFGH: `0x1800351c` (CNR), `0x18003524` (DIR), `0x18003528` (DAT).

### Коммутатор

* CPU-порт — порт 6 (EXT1, RGMII), 1000/full, задержки как в стоке: RX = 2 (600 пс), TX = 0.
  Их выставляет загрузчик; в eCos функции сброса RTL8367 и установки задержек
  есть, но не вызываются, так что в стоке работают значения загрузчика. DSA-драйвер
  сбрасывает коммутатор, поэтому те же значения заданы в DTS.
* Порты корпуса: **LAN1 = порт 3, LAN2 = порт 1, LAN3 = порт 0, WAN = порт 4**, порт 2 не разведён.
* В OpenWrt коммутатор обслуживает штатный DSA-драйвер `rtl8365mb` с аппаратным
  CPU-тегом RTL8197F, интерфейсы `lan1`, `lan2`, `lan3`, `wan`.
* Для ревизии чипа `0x81970000` сток дополнительно выставляет бит 1 в `P0GMIICR`
  (таймингах RGMII со стороны SoC) — это повторено в драйвере `rtl8197f-eth`.

## Карта флеш-памяти

| Смещение | Размер | Раздел OpenWrt | Содержимое |
|---|---|---|---|
| `0x000000` | 112 КиБ | `bootloader` (ro) | загрузчик Realtek v3.4.13 (RTL8197F-VG) |
| `0x01C000` | 4 КиБ | `factory` (ro) | **заводской NVRAM: MAC-адреса и калибровка Wi‑Fi** |
| `0x01D000` | 12 КиБ | `reserved` (ro) | не используется стоком |
| `0x020000` | 7.9 МиБ | `firmware` | образ `cs6c` (загрузчик ядра + ядро) + squashfs + overlay (jffs2) |

На штатной 2-МиБ флешке eCos держит свою конфигурацию в `0x1F0000` и `0x1F8000`;
OpenWrt её не использует.

Первые 128 КиБ уникальны для каждого роутера (MAC, калибровка) — **сохраните
дамп и никогда не стирайте раздел `factory`**.

## Загрузчик

* Проверяет только образ по адресу `0x20000`: 16-байтный заголовок `cs6c`
  (big-endian: адрес загрузки, адрес во флеше, длина) и 16-битную сумму
  big-endian слов полезной нагрузки, которая должна быть равна 0.
  Сигнатура `cr6c` дополнительно требует rootfs Realtek — не используется.
* Копирует нагрузку в ОЗУ по адресу из заголовка и прыгает на него.
  OpenWrt кладёт туда двухступенчатый lzma-loader (`0x80a00000` → `0x82000000`),
  который распаковывает ядро в `0x80000000`.
* Консоль UART 38400 8N1; `ESC` при включении — приглашение `<RealTek>`.
* TFTP-сервер загрузчика (IP по умолчанию `192.168.0.1`, меняется командой
  `IPCONFIG`): файл с именем **`nfjrom`** загружается в ОЗУ по `0xa0a00000` и
  запускается (без записи во флеш); остальные файлы при `AUTOBURN 1`
  проверяются и прошиваются по своему адресу. Удержание кнопки WPS/RST при
  включении переводит загрузчик в режим ожидания прошивки.

Генератор заголовка — `openwrt/target/linux/rtl819x/image/cvimg.py`; он
байт-в-байт воспроизводит заголовок стоковой прошивки.

## Заводской NVRAM (`0x1C000`)

Формат Broadcom NVRAM: `"FLSH"`, le32 полная длина (включая 20-байтный
заголовок), ещё три le32, затем строки `ключ=значение`, разделённые `\0`.
Посмотреть содержимое своего дампа: `python3 scripts/ac8_nvram.py дамп.bin`.

| Ключ | Пример | Используется |
|---|---|---|
| `et0macaddr` | `04:95:E6:29:74:B0` | MAC LAN и WAN (как в стоке), MAC на наклейке |
| `wl0_hwaddr` | `04:95:E6:29:74:B1` | MAC 2.4 ГГц |
| `wl1_hwaddr` | `04:95:E6:29:74:B5` | MAC 5 ГГц |
| `wps_device_pin` | `45939358` | пароль Wi‑Fi по умолчанию в этой прошивке |
| `HW_WLAN0_*` | — | калибровка **5 ГГц RTL8812F** |
| `HW_WLAN1_*` | — | калибровка **2.4 ГГц RTL8197F** |
| `country_code`, `REG_DOMAIN` | `US`, `d` | стоковый регион (не используется) |

### Калибровка радиомодулей

Имена параметров — это имена flash-items Realtek SDK с префиксом радиомодуля.
Значения шестнадцатеричные, таблицы — hex-строки по байту на канал. Драйвер
`rtl8192cd` (функция `realtek_load_flash_calibration`) читает блок через NVMEM
(ячейка `nvram` в DTS) и раскладывает его ровно так, как это делает eCos:

* 2.4 ГГц, таблицы по 14 каналам: `TX_POWER_CCK_A/B`, `TX_POWER_HT40_1S_A/B`,
  `TX_POWER_DIFF_HT40_2S`, `TX_POWER_DIFF_HT20`, `TX_POWER_DIFF_OFDM`,
  `TX_POWER_TSSI_CCK_A/B`, `TX_POWER_TSSI_HT40_1S_A/B`
  (+ `DIFF_20BW1S_OFDM1T_A/B`, `DIFF_40BW2S_20BW2S_A/B`, если есть).
* 5 ГГц: `TX_POWER_5G_HT40_1S_A/B` и `TX_POWER_TSSI_5G_HT40_1S_A/B` —
  177 байт, индекс = номер канала; `TX_POWER_DIFF_5G_*` — 14 групп каналов,
  разворачиваются по таблице eCos: 35-39, 40-47, 48-55, 56-63, 64-103,
  104-111, 112-119, 120-127, 128-135, 136-143, 144-152, 153-160, 161-168,
  169-176.
* Скаляры: `11N_XCAP` (подстройка кварца), `11N_THER`/`11N_THER_2`
  (термокалибровка), `11N_TSSI1/2`, `11N_TSSI_ENABLE` (оба радиомодуля в
  режиме TSSI), `11N_TRSWITCH`, `11N_TRSWPAPE_C9/CC`, `RF_TYPE`.
* RFE (тип обвязки) — 0 для обоих радиомодулей (внутренние PA/LNA), как в
  стоке; переопределяется параметрами модуля `rfe_soc=` и `rfe_pcie=`.
* Тип корпуса RTL8197F (97FB/97FN/97FS) драйвер определяет по регистру
  `0xb800000c`, как оригинальный BSP.
