# Установка OpenWrt на Tenda AC8 v1 (8 МиБ флеш)

> Прошивка рассчитана **только** на AC8 v1 с флешкой, заменённой на 8 МиБ.
> На штатной 2-МиБ флешке она не поместится.

Файлы из [релиза](../../releases):

| Файл | Для чего |
|---|---|
| `openwrt-ac8-<версия>-rtl819x-rtl8197f-tenda_ac8-v1-squashfs-sysupgrade.bin` | основной образ: программатор (через `mkflash.py`), обновление из OpenWrt |
| `openwrt-ac8-<версия>-rtl819x-rtl8197f-tenda_ac8-v1-initramfs-nfjrom.bin` | запуск OpenWrt из ОЗУ через TFTP загрузчика (восстановление, первая установка без программатора) |
| `sha256sums` | контрольные суммы |

## 0. Сохраните заводские данные

Первые 128 КиБ флешки (загрузчик + заводской NVRAM по `0x1C000`) уникальны для
вашего экземпляра: в них MAC-адреса и калибровка Wi‑Fi. Перед любыми работами
сделайте полный дамп и проверьте его:

```sh
python3 scripts/ac8_nvram.py ac8_dump.bin
```

Скрипт должен показать `AC8_V2.0`, MAC-адреса и таблицы мощности обоих
радиомодулей.

## 1. Программатор (рекомендуется)

1. Соберите полный образ 8 МиБ из своего дампа и `sysupgrade.bin`:

   ```sh
   python3 scripts/mkflash.py --dump ac8_dump.bin \
       --firmware openwrt-ac8-<версия>-rtl819x-rtl8197f-tenda_ac8-v1-squashfs-sysupgrade.bin \
       -o ac8-openwrt-full-8m.bin
   ```

   Скрипт берёт из дампа первые 128 КиБ (подходит дамп и старой 2-МиБ, и новой
   8-МиБ микросхемы), проверяет заголовок `cs6c` и контрольную сумму образа.

2. Запишите `ac8-openwrt-full-8m.bin` в микросхему (например CH341A):

   ```sh
   flashrom -p ch341a_spi -w ac8-openwrt-full-8m.bin
   ```

3. Первый запуск занимает 1–2 минуты (создаётся раздел настроек). Индикатор
   мигает во время загрузки и горит постоянно, когда система готова.

## 2. Без программатора: TFTP загрузчика + sysupgrade

Загрузчик Realtek умеет принимать файл по TFTP. Файл с именем `nfjrom`
запускается из ОЗУ, флешка при этом не меняется.

1. Задайте компьютеру адрес `192.168.0.2/24` и подключите его к порту LAN.
2. Переведите загрузчик в режим ожидания:
   * удерживайте кнопку **WPS/RST** и включите питание, держите ~5 секунд; или
   * через UART (38400 8N1) нажмите `ESC` при включении, в приглашении
     `<RealTek>` выполните `IPCONFIG 192.168.0.1`.
3. Отправьте initramfs-образ под именем `nfjrom`:

   ```sh
   tftp -m binary 192.168.0.1 -c put \
       openwrt-ac8-<версия>-rtl819x-rtl8197f-tenda_ac8-v1-initramfs-nfjrom.bin nfjrom
   ```

   (Windows: `tftp -i 192.168.0.1 PUT openwrt-...-initramfs-nfjrom.bin nfjrom`.)
4. Через ~30 секунд OpenWrt запустится из ОЗУ: компьютер получит адрес по DHCP,
   веб-интерфейс — <http://192.168.1.1>.
5. В LuCI откройте **Система → Резервная копия / Прошивка → Установить образ**
   и загрузите `sysupgrade.bin` (галочку «Сохранить настройки» снимите). Или по
   SSH: `sysupgrade -n /tmp/openwrt-...-sysupgrade.bin`.

> Адрес загрузчика и поведение кнопки определены по дизассемблированию загрузчика
> v3.4.13. Если загрузчик не отвечает, используйте UART.

## 3. После установки

* Веб-интерфейс: <http://192.168.1.1> (или https), пользователь `root`, пароль
  не задан — задайте его сразу (**Система → Администрирование**).
* Wi‑Fi включён: сети `OpenWrt-AC8-XXXXXX` (2.4 ГГц) и `OpenWrt-AC8-XXXXXX-5G`,
  WPA2/WPA3 (смешанный режим), **пароль — WPS PIN роутера** (8 цифр из
  заводского NVRAM, часто напечатан на наклейке). Узнать его:
  `python3 scripts/ac8_nvram.py дамп.bin` или в LuCI в настройках сети Wi‑Fi.
  Если PIN не найден, Wi‑Fi остаётся выключенным.
* Подключение к провайдеру: **Сеть → Интерфейсы → wan → Изменить**:
  DHCP (по умолчанию), статический адрес или **PPPoE**.
* Регион Wi‑Fi по умолчанию — RU, часовой пояс — Москва.
* Если какое-то устройство не подключается к Wi‑Fi в смешанном режиме
  WPA2/WPA3, переключите шифрование на **WPA2-PSK** (**Сеть → Беспроводная
  сеть → Изменить → Безопасность**) и сообщите о проблеме с логом
  `logread | grep -i -e hostapd -e wlan`.

## Обновление

Новые версии ставятся через LuCI (**Установить образ**) или `sysupgrade` с
файлом `*-sysupgrade.bin`. Образ проверяется по заголовку `cs6c` и метаданным
устройства.

С ранних экспериментальных сборок этого репозитория (OpenWrt 19.07/24.10,
теги `ac8-*`) переходите без сохранения настроек: `sysupgrade -n файл.bin`
(в LuCI — снимите «Сохранить настройки»).

Пакеты ядра (`kmod-*`) из официальных репозиториев OpenWrt для этой платформы
не подходят: платформа `rtl819x` не входит в официальную сборку. Нужные пакеты
добавляйте в сборку (см. [building.md](building.md)).

## Возврат на стоковую прошивку

Запишите программатором свой полный дамп, сделанный до установки.

## Восстановление

* Не загружается после обновления — способ 2 (TFTP `nfjrom`) и снова sysupgrade.
* Кнопка WPS/RST в OpenWrt: короткое нажатие — перезагрузка, удержание дольше
  5 секунд — сброс настроек (то же самое: `firstboot && reboot`).
* Failsafe: нажмите кнопку несколько раз, когда индикатор быстро мигает при
  загрузке, затем `telnet`/`ssh` на `192.168.1.1`.
