**Экспериментальная сборка: OpenWrt 19.07, Linux 4.14.** Платформа —
цель `rtkmipsel` порта
[Alcatel LINKHUB HH71VM](https://github.com/sowarden/hh71vm-openwrt),
Ethernet — драйвер SDK Realtek с кодом RTL8367RB из стоковой прошивки AC8
(как в форке для Tenda AC10U), Wi-Fi — вендорский драйвер без hostapd,
WPA2 считает сам драйвер. Прочитайте
[инструкцию](https://github.com/Aleck59/tenda_ac8_openwrt/blob/main/docs/flashing.md)
и держите под рукой UART: если что-то пойдёт не так, нужен лог от включения
питания.

**Исправлен бутлуп предыдущей сборки 19.07.** Загрузчик Tenda передаёт
образу в регистрах a0/a1 мусор (`0x8000ffe0`/`0x10000` — аргументы своей
последней очистки кэша). Загрузчик LZMA порта HH71VM принимал их за
argc/argv и записывал указатель на командную строку по адресу
`0x0004ff80`, где нет памяти: исключение вместо старта ядра. Теперь
загрузчик передаёт ядру свой argv, как загрузчик сборок 24.10, которые на
AC8 стартовали. Ещё в этой сборке:

- `mem=64M` в командной строке и 64 МБ по умолчанию в ядре: таблица
  определения объёма ОЗУ в коде HH71VM не знает RTL8197FH-VG;
- watchdog останавливается первой инструкцией загрузчика LZMA;
- драйвер Wi-Fi загружается в конце загрузки, под защитой от бутлупа: если
  роутер перезагрузился во время старта Wi-Fi, следующая загрузка
  оставит Wi-Fi выключенным (`/etc/ac8-wifi.failed`), а LAN и LuCI будут
  работать;
- oops ядра больше не перезагружает роутер (`PANIC_ON_OOPS` выключен).

**Если роутер в бутлупе после прошлой сборки**, прошейте эту из
загрузчика: `Esc` в UART при включении, затем `AUTOBURN 0`, TFTP и `FLW`
([вариант Б](https://github.com/Aleck59/tenda_ac8_openwrt/blob/main/docs/flashing.md#вариант-б-из-загрузчика-без-программатора)),
или программатором.

| Файл | Для чего |
|---|---|
| `*-{8m,16m}-fullflash.bin` | полный образ микросхемы 8/16 МБ **с загрузчиком** из `boot/` репозитория — только для роутера, с которого снят этот загрузчик: `flashrom -p ch341a_spi -w ...-fullflash.bin` |
| `*-{8m,16m}-squashfs-flash.bin` | раздел `firmware` с `0x20000`: из загрузчика (`FLW 20000 ...`) или программатором |
| `*-{8m,16m}-squashfs-sysupgrade.bin` | обновление из LuCI или `sysupgrade` |

**Со сборок 24.10 этого порта** обновляйтесь из LuCI или `sysupgrade -n`
**без сохранения настроек**: их настройки сети и Wi-Fi к 19.07 не подходят
(если сохранятся, первая загрузка сбросит сеть и Wi-Fi к значениям по
умолчанию).

**Настройки по умолчанию.** Роутер — `192.168.1.1/24`, на LAN работает
DHCP-сервер. LAN — гнёзда портов 0–3 коммутатора (`eth0`), WAN — порт 4
(`eth1`, DHCP-клиент). Wi-Fi включён: `Openwrt` (2,4 ГГц) и `Openwrt-5G`
(5 ГГц, канал 36, 80 МГц), WPA2-PSK, пароль `12345678`; сети появляются
примерно через минуту после LAN. LuCI на русском.

**Что изменилось по сравнению с 24.10.**

- Коммутатор RTL8367RB инициализирует код SDK Realtek (`rtl8367b_*`), тот
  же, что в стоковой прошивке: сброс, `rtk_switch_init`, EXT1 RGMII с
  задержками tx 0 / rx 5, светодиоды портов, пороги, SSC; VLAN LAN/WAN
  настраивает драйвер. SMI — GPIO H0/G7, пады и задержки P0 SoC — как в
  стоке. Никаких `swconfig reset` при загрузке.
- Wi-Fi настраивается как в стоке: `iwpriv set_mib`, без cfg80211 и
  hostapd. Калибровка радио (таблицы мощности, `xcap`, `ther`, TSSI) и
  MAC-адреса берутся из данных платы Tenda во флеше. RFE встроенного
  радио — тип 0 (внутренние PA/LNA), как в стоке.
- Кольца драйвера Wi-Fi уменьшены под 64 МБ ОЗУ.
