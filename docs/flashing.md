# Запуск и прошивка Tenda AC8 v1 (OpenWrt 19.07)

Порядок важен: **резервная копия → запись во флеш → проверка**.
Переходите к следующему шагу, только если предыдущий прошёл.

Что понадобится:

- USB-UART адаптер на **3,3 В** (CP2102, CH340, FT232). 5 В сожгут SoC;
- программатор CH341A и клипса SOIC-8. Без них восстановить роутер после
  ошибки при записи загрузчика не получится;
- TFTP-клиент на ПК (`tftp-hpa` в Linux, `tftp` в Windows), если шить
  из загрузчика без программатора;
- новая микросхема SPI NOR на 3,3 В: W25Q64JVSIQ (8 МБ) или
  W25Q128JVSIQ (16 МБ). На стоковые 4 МБ прошивка не помещается.

## 1. Резервная копия флеша

Снимите полный дамп оригинальной микросхемы **дважды** и сравните:

```sh
flashrom -p ch341a_spi -r ac8-stock-1.bin
flashrom -p ch341a_spi -r ac8-stock-2.bin
sha256sum ac8-stock-*.bin      # суммы должны совпасть
```

Храните дамп в надёжном месте. В нём загрузчик, MAC-адреса и калибровка
радио вашего экземпляра (область `0x1c000–0x20000`), взять их больше
неоткуда. OpenWrt читает их оттуда же: MAC-адреса Ethernet и Wi-Fi и
таблицы мощности передатчиков.

По смещению `0x20000` должен начинаться заголовок `cs6c`:

```sh
dd if=ac8-stock-1.bin bs=1 skip=$((0x20000)) count=16 2>/dev/null | xxd
# 00000000: 6373 3663 ....        cs6c....
```

Если там другое, **не шейте**: раскладка вашей ревизии отличается.

## 2. UART и загрузчик

На плате есть 4-контактный разъём UART (GND, TX, RX, VCC). VCC **не
подключайте**. Ядро OpenWrt выводит лог на **115200**; загрузчик Realtek
работает на 38400 или 115200.

При включении питания жмите `Esc` в терминале. Должно появиться
приглашение `<RealTek>`. Загрузчик работает как TFTP-сервер, обычно на
`192.168.1.6`. Задайте ПК адрес `192.168.1.100/24` и подключите кабель в
LAN-порт.

## 3. Запись во флеш

Разделы OpenWrt:

| Раздел | Флеш 8 МБ | Флеш 16 МБ | Что там |
|---|---|---|---|
| `boot` | `0x000000–0x020000` | то же | загрузчик и данные платы, только чтение |
| `firmware` | `0x020000–0x7e0000` | `0x020000–0xfe0000` | ядро (`cs6c`), SquashFS, JFFS2 с настройками |
| `tenda_config` | `0x7e0000–0x800000` | `0xfe0000–0x1000000` | конфигурация Tenda, только чтение |

Образ ставится под свой размер флеша: `*-8m-*` на 8 МБ, `*-16m-*` на
16 МБ.

### Вариант А: программатор (первая установка, замена микросхемы)

`*-{8m,16m}-fullflash.bin` из Releases — загрузчик из
`boot/tenda_ac8-v1-boot.bin` репозитория + OpenWrt на всю микросхему (см.
[boot/README.md](../boot/README.md)). Годится только для роутера, с
которого снят этот загрузчик:

```sh
flashrom -p ch341a_spi -w openwrt-rtkmipsel-rtl8197f-tenda_ac8-v1-16m-fullflash.bin
```

Из своего дампа — скриптом
[`scripts/make-fullflash.py`](../scripts/make-fullflash.py):

```sh
python3 make-fullflash.py --backup ac8-stock-1.bin \
    --firmware openwrt-rtkmipsel-rtl8197f-tenda_ac8-v1-16m-squashfs-flash.bin \
    --size 16M --output ac8-openwrt-16m-full.bin
flashrom -p ch341a_spi -w ac8-openwrt-16m-full.bin
```

Только прошивку, не трогая загрузчик: без `--backup`/`--boot` скрипт
делает образ размером с микросхему и файл `.layout`:

```sh
python3 make-fullflash.py \
    --firmware openwrt-rtkmipsel-rtl8197f-tenda_ac8-v1-8m-squashfs-flash.bin \
    --size 8M --output ac8-update-8m.bin
flashrom -p ch341a_spi -l ac8-update-8m.bin.layout -i firmware -w ac8-update-8m.bin
```

### Вариант Б: из загрузчика (без программатора)

Загрузите `*-squashfs-flash.bin` в RAM по TFTP. В консоли загрузчика:

```text
<RealTek>AUTOBURN 0
<RealTek>LOADADDR 80a00000
```

`AUTOBURN 0` обязательно: иначе загрузчик сам начнёт писать принятый
образ во флеш. На ПК:

```sh
tftp -m binary 192.168.1.6 -c put openwrt-rtkmipsel-rtl8197f-tenda_ac8-v1-8m-squashfs-flash.bin
```

Затем запишите образ:

```text
<RealTek>FLW 20000 80a00000 <размер_файла_hex> 0
```

- `20000` — смещение во флеше, **не меньше `20000`**: ниже лежит загрузчик;
- размер — длина файла в hex (`printf '%x\n' $(stat -c %s файл)`).

### Вариант В: со сборок OpenWrt 24.10 этого порта (до `ac8-20260928-26`)

**Система → Резервное копирование / Прошивка → Установить новую
прошивку**, файл `*-squashfs-sysupgrade.bin` своего размера флеша.
**Снимите галочку «Сохранить настройки».** Из консоли:

```sh
sysupgrade -n /tmp/openwrt-rtkmipsel-rtl8197f-tenda_ac8-v1-8m-squashfs-sysupgrade.bin
```

Настройки 24.10 (VLAN коммутатора `eth0.1`/`eth0.2`, Wi-Fi через
mac80211, тема footstrap) к 19.07 не подходят. Если они всё же
сохранились, первая загрузка сбросит сеть и Wi-Fi к значениям по
умолчанию, а старые файлы оставит как `/etc/config/*.24.10`.

### Вариант Г: обновление 19.07 → 19.07

Из LuCI или `sysupgrade`, «Сохранить настройки» работает.

## 4. Проверка после загрузки

Адрес роутера — `192.168.1.1/24`, DHCP-сервер на LAN включён: на ПК
оставьте получение адреса автоматически. ПК подключайте в **LAN-гнездо**:
WAN — порт 4 коммутатора, там роутер сам ждёт адрес от провайдера.
Wi-Fi включается сам: `Openwrt` (2,4 ГГц) и `Openwrt-5G`, WPA2-PSK,
пароль `12345678`. Поменяйте пароль в **Сеть → Беспроводные сети**.
Драйвер Wi-Fi загружается в самом конце загрузки (скрипт
`/etc/init.d/ac8-wifi`), поэтому сети появляются примерно через минуту
после того, как заработали LAN-порты.

Лог UART от включения до входа в систему сохраните целиком. В нём должно
быть:

```
Starting kernel at 80000000...
Linux version 4.14.275 ...
Kernel command line:  console=ttyS0,115200 mem=64M rootfstype=squashfs mtdparts=m25p80:...
Machine: Tenda AC8 v1
rtl8197f-fw: firmware split kernel=0x... rootfs=0x...
rtl8197f-fw: firmware rootfs_data=0x...+0x...
```

и строки драйверов Ethernet и Wi-Fi (`RTL8367R`, `rtl8192cd`,
`RFE TYPE =0`). Если после `Starting kernel` ничего нет — пришлите лог.

После загрузки:

```sh
cat /proc/mtd              # boot, firmware, tenda_config, kernel, rootfs, rootfs_data
df -h /overlay             # JFFS2: настройки и пакеты
ip -br link                # eth0 (LAN), eth1 (WAN), wlan0, wlan1
dmesg | grep -iE '8367|rtl819x|rtl865x|link'
iwconfig                   # точки доступа wlan0 (2,4 ГГц), wlan1 (5 ГГц)
logread | grep rtl8192cd   # ошибки настройки Wi-Fi, калибровки
```

Подключите кабель по очереди в каждое гнездо: LAN-гнёзда должны давать
адрес по DHCP, WAN — нет (он клиент провайдера).

### Если роутер перезагружается по кругу

Прошивку можно вернуть без программатора, из загрузчика. Подключите UART,
при включении питания жмите `Esc` до приглашения `<RealTek>` и запишите
другой `*-squashfs-flash.bin` по [варианту Б](#вариант-б-из-загрузчика-без-программатора).
Загрузчик и данные платы
(`0x0–0x20000`) прошивка OpenWrt не трогает, поэтому он остаётся рабочим.

Лог UART нужен от включения питания до первой перезагрузки: по нему видно,
на каком шаге всё останавливается — в загрузчике LZMA (`Decompressing
kernel...`), в ядре или в драйвере.

### Если не появился Wi-Fi

Драйвер Wi-Fi загружается под защитой от бутлупа. Перед загрузкой драйвера
скрипт `/etc/init.d/ac8-wifi` создаёт файл `/etc/ac8-wifi.loading`
и удаляет его через две минуты после настройки радио. Если в это время
роутер перезагрузился, следующая загрузка переименует файл в
`/etc/ac8-wifi.failed` и оставит Wi-Fi выключенным, а LAN и LuCI будут
работать:

```sh
logread -e ac8-wifi            # что сделал скрипт
dmesg | grep -i -A20 rtl8192cd # что успел сказать драйвер
```

Повторить попытку: `rm /etc/ac8-wifi.failed; reboot`, или загрузить
драйвер сразу: `/etc/init.d/ac8-wifi start` (тогда держите включённым лог
UART: падение драйвера может перезагрузить роутер).

### Если что-то не работает

Пришлите:

- лог UART от включения питания;
- `dmesg` и `logread` целиком;
- вывод:

```sh
cat /proc/mtd
ip -s link
cat /etc/config/network /etc/config/wireless
ls /proc/rtl865x/ && cat /proc/rtl865x/port_status
cat /proc/wlan0/mib_rf | head -40
cat /proc/wlan1/sta_info
```

Wi-Fi: клиенты точки доступа — `cat /proc/wlanN/sta_info` (в этой сборке
файлы `/proc/wlanN/*` читать можно). Ошибки `iwpriv` при настройке —
в `logread`: сообщения `rtl8192cd: ...`. Строки
`calibration ... not applied` означают, что драйвер не принял значение
калибровки из данных платы: точка доступа при этом работает, но мощность
может отличаться от стоковой.

## 5. Возврат на стоковую прошивку

Запишите сохранённый дамп программатором:

```sh
flashrom -p ch341a_spi -w ac8-stock-1.bin
```

Если микросхема заменена на 8/16 МБ, дополните дамп байтами `0xFF` до
размера микросхемы (flashrom требует точный размер) и запишите его:

```sh
cp ac8-stock-1.bin ac8-stock-16m.bin
head -c $((16*1024*1024 - 4*1024*1024)) /dev/zero | tr '\000' '\377' >> ac8-stock-16m.bin
flashrom -p ch341a_spi -w ac8-stock-16m.bin
```

Или впаяйте обратно оригинальную микросхему.
