# Загрузчик для полного образа (fullflash)

Положите сюда файл `tenda_ac8-v1-boot.bin` — первые 128 КБ (`0x0–0x20000`)
полного дампа флеша вашего роутера:

```sh
dd if=ac8-stock-1.bin of=tenda_ac8-v1-boot.bin bs=64k count=2
ls -l tenda_ac8-v1-boot.bin      # ровно 131072 байта
```

Загрузить его можно через GitHub: **Add file → Upload files** в папку
`boot/`, коммит в `main`. После этого сборка сама запустится и выложит в
Releases `*-{8m,16m}-fullflash.bin`: образ на всю микросхему с вашим
загрузчиком. Его можно целиком записать на чистую новую микросхему:

```sh
flashrom -p ch341a_spi -w openwrt-realtek-rtl8197f-tenda_ac8-v1-16m-fullflash.bin
```

Важно:

- в этой области лежит загрузчик **вашего** экземпляра и, скорее всего,
  его MAC-адреса и калибровка радио. Держите репозиторий приватным;
- полный образ годится только для этого роутера. На другом AC8 будут
  чужие MAC-адреса и калибровка;
- загрузчик от другой модели (например, Tenda AC23) не подходит: у него
  прошивка начинается с `0x30000`, а у AC8 — с `0x20000`.
