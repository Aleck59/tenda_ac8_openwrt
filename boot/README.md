# Загрузочная область Tenda AC8 v1

Файлы для сборки полного образа флешки 8 МиБ (`*-full-8m.bin` в релизах).
Получены из дампа программатора роутера (`ac8_good_dump`) скриптом
`scripts/ac8_boot.py`:

```sh
python3 scripts/ac8_boot.py ac8_good_dump.bin -o boot
```

| Файл | Адрес во флеше | Содержимое |
|---|---|---|
| `bootloader.bin` | `0x00000–0x1BFFF` | загрузчик Realtek v3.4.13 (RTL8197F-VG), байт в байт из дампа; данных конкретного экземпляра в нём нет |
| `factory-reference.bin` | `0x1C000–0x1FFFF` | заводской NVRAM (`FLSH`) только с `BOARD_NAME` и калибровкой Wi‑Fi `HW_*` того роутера, с которого снят дамп |

Из заводского блока **намеренно удалены** MAC-адреса (`et0macaddr`,
`wl0_hwaddr`, `wl1_hwaddr`), серийные номера, WPS PIN (в этой прошивке он
служит паролем Wi‑Fi по умолчанию), региональные значения стока и отметки
заводских тестов: репозиторий публичный.

Что это значит для полного образа из релиза:

* роутер загружается и работает; мощность Wi‑Fi берётся из эталонной
  калибровки (для «своего» роутера она совпадает с родной, для других AC8 —
  близкая, но не родная);
* MAC-адреса LAN/WAN и Wi‑Fi OpenWrt генерирует при первой загрузке и хранит
  в настройках;
* Wi‑Fi по умолчанию выключен (нет WPS PIN для пароля), включите его в LuCI.

Чтобы сохранить **свои** MAC, PIN и калибровку, используйте ваш дамп:
`scripts/mkflash.py --dump ваш_дамп.bin --firmware <full-8m.bin или sysupgrade.bin> -o образ.bin`
или запишите программатором только области загрузчика и прошивки
(см. [docs/install.md](../docs/install.md)).

Контрольные суммы — `SHA256SUMS`.
