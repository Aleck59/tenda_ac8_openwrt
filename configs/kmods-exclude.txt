# Kernel module packages left out of the package feed (CONFIG_ALL_KMODS
# builds every other one, see scripts/configure.sh).  One extended regex
# per line, matched against the whole package name.  The Tenda AC8 has no
# USB port, no PCI slot and no audio or video, so drivers for those only
# cost build time; the feed stays under the 1000 files of a GitHub release.
# The Wi-Fi drivers of the mac80211 and mt76 packages are always left out
# (configure.sh), whatever this list says.
